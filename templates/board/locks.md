# 全局资源锁

> **所有 Bot 共用一台云电脑。** 下面这些资源是全局唯一的，两个 Bot 同时用一定出事。
> 加锁 = 追加一行并 `git push origin HEAD:main` 成功（git 提供原子性）。
> 解锁 = 删除自己那一行并 push。
> 超时 1 小时 → 总督或运维官有权强制回收并记录。

详见 `/sop-lane-lock`。

## 纪律

1. 用完**立刻**释放。不要"等下还要用"就一直占着。
2. 预计释放时间**保守估计**。宁可写 30 分钟然后提前释放。
3. 拿不到锁**不要硬来**。把任务状态改成 BLOCKED，写清在等什么锁。
4. 锁等待频繁出现在心跳里 = 架构问题，@运维 O1 想办法消除共享。
