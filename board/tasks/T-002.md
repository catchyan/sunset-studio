# T-002 · Framework v3: close the audit findings before any task is dispatched

- Owner: @Q1
- Reviewer: @human
- Milestone: S0
- Release condition it advances: S0 — "one project has run one task end to end under the
  framework". It could not, and this is why.
- Size exception: the audits found defects in every gate, both workflows, the constitution,
  eleven role cards and three SOPs. Splitting them means merging a framework that is
  internally inconsistent at each intermediate step, through gates that are half-fixed.

used to dispatch a task without the first agent hitting a wall the framework built.

## 4. Contracts

None frozen. The ownership table's format (`docs/03-gates/ownership-schema.md`) is unchanged;
only its content and how the gate reads it changed.

## 5. Definition of done

- [ ] No external value is interpolated into a `run:` step in either workflow.
- [ ] The lane gate reads the ownership table and the task card from the base branch.
- [ ] The ownership table is chosen by repository kind, not by which file exists.
- [ ] A rename is checked at both its source and its destination.
- [ ] Granted paths are read from a fenced block only.
- [ ] Peer review is enforced: `APPROVED-BY` from someone who is neither the branch's bot
      nor the card's owner.
- [ ] A diff touching the workflow, the gates, or an ownership table requires
      `APPROVED-BY: human`, and break-glass does not waive it.
- [ ] `board/<CODE>/<slug>` branches merge without a card or an evidence pack.
- [ ] `board/andon.md` and `board/blockers/**` merge without an approval.
- [ ] Every `EXIT_CODE` line in an evidence pack must be zero, and `command.txt` must equal
      section 6 exactly.
- [ ] The mirror gate compares the upstream file set against the manifest.
- [ ] A project gets a working CI workflow from the mount rather than writing one.
- [ ] `skipped` does not count as `success`.
- [ ] Branch protection is checkable from outside, and R11 checks it weekly.
- [ ] The constitution claims no enforcement that does not exist.
- [ ] No role card lists ownership globs.
- [ ] H2 has a rubric whose answers are comparable between milestones.
