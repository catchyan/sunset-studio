# T-000 · Framework v2: English, derived state, cut unenforced rules

- Owner: @A1
- Reviewer: @human
- Milestone: S0
- Release condition it advances: every gate implemented, wired, and watched failing
- Size exception: a framework rewrite has no split that leaves the repository consistent at each step; the gates, their shared library, and the documents describing them have to move together

> Written and executed **before any bot exists**, so there was no dispatcher to write this
> envelope; it was written alongside the work rather than before it. The human reviews and
> merges. Once agents are staffed, neither shortcut is available: cards are written at
> dispatch, and the reviewer is another agent.

## 1. Goal

The framework is in English, its rules are ones the gates actually enforce, and task state is
read from git rather than written by hand.

## 2. Inputs

- The audit of the SOP and role layer, and the audit of the gate implementations, both run
  before staffing.
- `docs/00-charter/studio-charter.md`, `docs/00-charter/constitution.md` as they stood at
  v1.0.3.
- The four incidents recorded in `CHANGELOG.md` for v1.0.1 through v1.0.3.

## 3. Lane

Every path in this repository. This is a rewrite carried out before the team exists; an
equivalent change afterwards must be split across lanes.

The first two are `HUMAN`-owned and need the `human-change` label. The rest need
`lane-override`. Both labels are declared here on purpose: they are counted separately, and
the gatekeeper reviews every pull request carrying either.

## 4. Contracts

The mirror contract changes shape: owner tokens are now ASCII, and `<TASK>` is a new glob
token. Projects on v1 must rewrite their ownership table when they upgrade. That is what
makes this a major version.

## 5. Definition of done

- [x] Every document and every gate message is ASCII English.
- [x] Task cards carry no status field; `tools/board/status.mjs` derives it from git and CI.
- [x] Self-reported heartbeats are gone; `tools/board/stall.mjs` reports only stopped lanes.
- [x] Evidence paths resolve, via the `<TASK>` token and the `TASK-AUTHOR` owner.
- [x] Overrides require a label plus a declaration on the card; free-text overrides are gone.
- [x] `HUMAN` paths have a legal amendment route.
- [x] Commit task ids and the acceptance command are actually verified, not merely documented.
- [x] `spec-check.mjs` rejects a documented gate that no CI job implements, and a blocking
      gate that swallows its own failures.
- [x] Locking works within branch protection instead of against it.
- [x] SOPs 17 to 6, routines 11 to 10, constitution 20 articles to 14, board 20 paths to 11.
- [x] This repository runs the same envelope gate it asks projects to run.
