# T-001 · The mount produced a mirror the mirror gate rejects

- Owner: @A1
- Reviewer: @human
- Milestone: S0
- Release condition it advances: a project can mount the framework and pass G1

> Emergency patch, under the clause in `docs/05-studio/versioning.md`. v2.0.0 cannot be
> adopted by anyone: the first project to mount it failed G1 on the mount's own output.

## 1. Goal

`node tools/mount.mjs --version <tag>` in an empty project produces a tree that passes
`node tools/studio-sync.mjs` without anything being edited by hand.

## 2. Inputs

- The failure: mounting v2.0.0 into the game repository reported
  `docs/_studio/README.md is not in the manifest`.
- `tools/mount.mjs`, `docs/03-gates/gates.md` section G1, and the mirror gate as the first
  project had to hand-write it.

## 3. Lane

`tools/mount.mjs`
`tools/gates/envelope-check.mjs`
`templates/tools/studio-sync.mjs`
`docs/03-gates/gates.md`
`docs/00-charter/constitution.md`
`OWNERSHIP.md`
`CHANGELOG.md`
`board/**`
`.gitattributes`
`.github/workflows/**`

`docs/00-charter/constitution.md` is `HUMAN`-owned and needs the `human-change` label; the
change to it is a wrong article count and no rule is touched. The rest need `lane-override`.

## 4. Contracts

The mirror now contains `templates/tools/studio-sync.mjs`, and a mounted project is expected
to hold a copy of it at `tools/studio-sync.mjs`. Projects on v2.0.0 pick this up by
re-mounting; nothing they have written breaks.

## 5. Definition of done

- [x] The mirror read-me is written before the manifest, so it is hashed like everything else.
- [x] `mount.mjs` installs `tools/studio-sync.mjs` from the template.
- [x] The mirror gate compares itself against that template on every run.
- [x] The mirror gate asks git whether the `-text` rule is in effect, rather than assuming it.
- [x] `gates.md` describes all three layers, and the constitution's article count is right.
- [x] G7 reads the changelog diff rather than the pull request body, and interpolates no
      untrusted text into a shell command.

## 6. Acceptance command

```bash
node tools/gates/gates.test.mjs
node tools/gates/selfcheck.mjs
node tools/gates/spec-check.mjs
```

## 7. Evidence

`evidence/T-001/` — command.txt, output.txt ending in EXIT_CODE=0, diff-stat.txt, env.txt.
The mount itself is proved in the game repository, which is where a mirror exists to verify.

## 8. Timeout and escalation

Same day. Every project is blocked until this ships.
